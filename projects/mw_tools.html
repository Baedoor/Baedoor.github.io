TES III: Morrowind is foundational game for my gamedev and worldbuilding journey. When I got into its modding scene I was enchanted by the dedication poured into it and organisational skills of PTR team. It wasn't long before I wanted to help with my little coding skills I had, creating small tools to help with some everyday modder tasks.

MoET

MoET is, despite its pompous name, simply a tool to calculate northmarker rotation. It serves as offline alternative to PTR's bot and has a bit more intuitive GUI.
Originally it was meant to be swiss knife tool with various utilities, and it is not impossible I may come back and rewrite it, merging all tools into one.

TOr

It's tool to reorder .esm and .esp files, so they show up correctly in Launcher. This tool was made mostly by my stubborness to not use Wrye Mash/MO2 that offered the same feature, so I thought this could be a fun way to do that instead.

Gridmap Legend Generator

It's a tool created exclusively for PTR, as a way to help with creation of legends for gridmaps. It allows generating of legend(s) through predefined settings.
This tool has some technical issues (most notably the PoI icons needing to be of specific size) so in the future this generator may be rewritten.
