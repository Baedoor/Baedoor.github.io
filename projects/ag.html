Guide

Airship Guard is a Discord bot written to help with my server, but expanded to make it useful universally.
Created in 27th of December 2022, it was initially written in Rust language and had variety of features and commands that were hardcoded.
Over time, the amount of them expanded even more, with bot getting some modularity to allow for more flexible use. The code however grew in complexity, and with me wanting to move on from Rust (as from learning experience, I wanted to make bot a proper application with practical use) the decision of rewrite was made.

On 1st June 2025, the process began, with 27th June marking the day of first Nim-based version (1.1.0) being released.
The rewrite focused on minimising its feature complexity and instead follow the example established in Project Tamriel's bot to allow server owners to decide on how far bot's usability should be done. Unlike PT's bot, however, Airship Guard is coded to be more modular, allowing multiple servers to customise it to their needs.

Availability & Safety

Airship Guard is currently hosted locally, meaning its availability varies heavily depending on host's computer being turned on.
This will change in the future, as the plan for the bot is to be rehosted on either some purchased server or separate device. It is not possible currently, however, meaning the bot will not run 24/7, and can have entire days of being unavailable.
Additionally, the list of labels - due to how bot is currently hosted - is managed locally and coordinated through (private) GitHub repository. This won't be needed when the hosting shifts, but as long as the current system is held, it is recommended to not post any particularly personal or sensitive contents until this changes.
To keep yourself up-to-date on Airship Guard development, feel free to join the server.
