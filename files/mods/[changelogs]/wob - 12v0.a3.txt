                             CHANGELOG:

IMPORTANT. DO READ "CRUCIAL TECHNICAL CHANGES" PART OF THIS CHANGELOG. MOST OF ITEMS/BLOCKS FROM PREVIOUS VERSION OF THIS MOD WILL DISAPPEAR AFTER UPDATING.
"Crucial Technical Changes" section gives you tips how to make some of these items last.

Firearm shooting mechanics is temporary. It is meant to be fun exclusive for anyone wanting to test earliest port versions. It will be patched as soon as I find solution.
Expect this version being more "insight into developer's progress" than strictly playable mod. It can be used in survival freely, but can contain bugs or unfinished elements.

CRUCIAL TECHNICAL CHANGES
Refactored a lot of IDs, so a lot of elements will be missing after updating
  > it will make more intuitive using of commands (previously items have no "_" elements)
  > this will enable possible moving from 1.12 into 1.14/1.15/1.16 (theoretically, not guaranteed though) since IDs will be the same
How to make some items not disappear:
  > if you have javelins, craft javelin sacks (they will stay)
  > if you have charcoal blocks, turn them into charcoal for that time
