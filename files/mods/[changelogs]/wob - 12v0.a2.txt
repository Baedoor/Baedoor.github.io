                             CHANGELOG:

Firearm shooting mechanics is temporary. It is meant to be fun exclusive for anyone wanting to test earliest port versions. It will be patched as soon as I find solution. Also, wandering merchant feature is disabled by default, as it's bugged. It can be turned on via commands though. In 12v0.a3 I expect both bugs being fixed - therefore I release this version, because I don't know how long it will take to solve them.
Expect this version being more "insight into developer's progress" than strictly playable mod. It can be used in survival freely, but can contain bugs or unfinished elements.
